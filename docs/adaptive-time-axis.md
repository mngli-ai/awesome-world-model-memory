# 密度自适应时间轴

`build_map.py` 从 `research-map.yaml` 自动计算，不需在每轮论文入库后手调。

- 每条大分类独立时间轴，分类内部所有分支共享同一组时间列。
- 空月份、空区间不占位；列宽相同，不表示实际时间长度相同。
- 稀疏月份仍占一列；任一分支超过 `MAX_STACK = 3` 篇时，将该月按上旬（1–10）、中旬（11–20）、下旬（21–月末）拆分。
- 拥挤的旬再分为前五日、剩余日期（末段可能六天）；仍拥挤则分到单日。稀疏区间不继续拆。
- 同一天超过三篇时增设相同日期的“续2”“续3”列，不伪造新的日期。
- 月精度或未知精度的论文，在需要拆分月份时放入“未定日”列，不把 YAML 占位日期当作真实日期。
- 每列顶部显示明确区间，浅虚线只贯穿本分类；年份与原有分类导航、缩放、搜索、论文详情保留。
- 阈值是每个分支在一个时间列里的容量，而不是整个分类的论文总数，避免多分支的稀疏月份被过度拆分。

## 验证与重建

```sh
python -m unittest test_layout -v
python build_map.py research-map.yaml index.html "World Model Memory Atlas · 世界模型记忆图谱"
```

不要用旧派生文件 `research-map-online.yaml` 替代主表重建，此文件并非当前完整入库数据。

回归覆盖稀疏月份、旬级拆分、上旬密集、同日续列、日期精度、闰月和完整主表的卡片无重叠。
